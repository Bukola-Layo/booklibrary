# BookNook

A personal, interactive bookshelf built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Note

This repository contains a demo curation of books with a 3D carousel, book detail views, and reading previews. Book data lives in `data/books.ts` and can be edited to personalize the library.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Scripts

- `npm run dev` - start the development server
- `npm run build` - create a production build
- `npm run start` - serve the production build
- `npm run lint` - run ESLint
- `npm run typecheck` - run TypeScript checks
